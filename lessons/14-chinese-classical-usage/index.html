《劝学》默写易错点订正

✍️ 字形与偏旁规范

  • 跬步：足字旁，很多同学写错
  • 砺：磨刀石，石字旁，右边是严厉的「厉」非「角」
  • 蟹六跪：蟹下面是虫字旁，非竹字头；六跪指蟹的脚
  • 鳝：鱼字旁，非虫字旁；蛇才是虫字旁

🔍 通假字与虚词

  • 知明而行无过：知通「智」，智慧
  • 有槁暴：有通「又」
  • 輮以为轮：輮通「煣」，用火烤使木弯曲
  • 语气词不能漏：「吾尝终日而思矣」「不如登高之博见也」

⚠️ 常见错误警示

  • 至 / 致：「善假于物致千里」反文旁；「无以至千里」是「至」
  • 尝：此处意为「曾经」，非「尝试」
  • 性非异也：性通「生」，本性

词类活用判定原理：句子成分分析法

🧠 核心定义词类活用 = 一个词在具体语境中改变了原有词性，具有临时性和语境依赖性。判断依据：参照现代汉语语法习惯分析句子成分——某位置按规定应由特定词性充当，却出现了其他词性，即发生活用。
句子成分正常词性出现「错位」→ 活用结论
主语 / 宾语名词 / 代词出现动词、形容词 → 活用作名词
谓语动词 / 形容词出现名词 → 活用作动词
定语形容词 / 名词修饰名词 / 代词
状语副词 / 形容词修饰动词 / 形容词
补语形容词 / 数量词补充说明动词 / 形容词
🏗️ 句式结构基础现代汉语句式主要是「主谓」和「主谓宾」结构。谓语是句子中唯一不可省略的成分，翻译时先找准谓语动词。例：「林间的小鸟用力地啄破了饱满的果实」→ 缩句「小鸟啄果实」，「林间」定语、「用力」状语、「破」补语。

活用类型与典型实例

📦 名词活用

  • 名作动：「衣冠禽兽」（穿衣戴帽）、「王无罪岁」（归罪）、「籍吏民」（登记造册）
  • 名作状：处所（内/对外）、工具（笼/用笼子）、态度（兄/像对待兄长）、时间（朝/夕）、方位（东/西/上/下）
  • 意动用法（主观认为）：「草菅人命」（把…当作草）、「侣鱼虾而友麋鹿」（以…为伴侣/朋友）

⚡ 动词与形容词活用

  • 动作名：「追亡逐北」（逃亡的人/败逃的军队）、「其至又加少矣」（到达的人）
  • 使动用法（客观致使）：「富国强兵」（使…富足/强大）、「舞幽壑之潜蛟」（使…起舞）
  • 形作名：「温故知新」（旧知识/新知识）、「救死扶伤」（垂死的人/受伤的人）
  • 形作动：「耳熟能详」（详细说）、「善张良」（与…交好）

⚖️ 特殊语法现象辨析

  • 偏正关系：两个名词连用意义偏后，如「国家」「窗户」「府库」
  • 并列关系：如「吏民」（官吏和百姓）；若名词夹杂其间又不构成并列/偏正 → 该名词活用作动词
  • 能愿动词后：「非能水也」，「能」后接名词 →「水」活用作动词（游泳）
🎯 使动 vs 意动 一字诀使动 = 客观致使宾语产生某种结果（使它怎样）；意动 = 主观认为（把它当作什么）。名作动 vs 名作状：看句中有没有主要动词——有主要动词则名词作状语，没有则名词作谓语（动词）。

真题演练与解题思路

① 《游褒禅山记》「则其至又加少矣」
「至」位于主语位置，原为动词「到达」→ 活用作名词，译为「到达的人」。依据：主语通常由名词充当。
② 《孟子》「王无罪岁」
「罪」位于谓语位置，原为名词「罪过」→ 活用作动词，译为「归罪」。依据：谓语通常由动词充当；「无」是否定副词修饰谓语。
③ 《史记》「高祖为赏首」
「先」结合「赏有功者」语境为意动用法或名作动，译为「把…放在前面/最先奖赏」。依据：张贺无功却受首赏，「先」体现主观上的优先处理。
④ 《赤壁赋》「泣下如雨」
「下」位于谓语位置，方位名词 → 活用作动词「落下」。对比：「上食埃土」的「上」修饰动词「食」作状语（向上）。区别：有无主要动词决定方位名词作谓语还是状语。
