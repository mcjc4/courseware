9. 实验室用铝合金(含 Al、Cu)制备 Al₂O₃，下列相关原理、装置及操作正确的是(　　)
A. 用图甲装置溶解铝合金（蒸发皿加热）
✗ 装置甲错误。蒸发皿用于蒸发结晶，不能用来溶解固体。溶解应在烧杯或锥形瓶中进行。反应：$2Al + 3H_2SO_4 = Al_2(SO_4)_3 + 3H_2 \uparrow$；Cu 与稀硫酸不反应。
B. 用图乙装置过滤溶解后混合物
✓ B 正确。溶解后混合物含 $Al_2(SO_4)_3$ 溶液和 Cu 残渣，用过滤装置分离。图乙中漏斗下端紧靠烧杯内壁、玻璃棒引流，操作规范。
C. 用图丙加过量 NaOH 溶液制备 Al(OH)₃
✗ 丙错误。Al(OH)₃ 是两性氢氧化物，能溶于过量 NaOH：$Al(OH)_3 + NaOH = NaAlO_2 + 2H_2O$。应加入适量 NaOH 或氨水才能得到 Al(OH)₃ 沉淀。
D. 用图丁装置灼烧 Al(OH)₃ 制 Al₂O₃（蒸发皿）
✗ 丁错误。灼烧固体应在坩埚中进行（可承受高温、不会炸裂），蒸发皿只适合蒸发液体。反应：$2Al(OH)_3 \xlongequal{\Delta} Al_2O_3 + 3H_2O$

✓详细解析

制备 Al₂O₃ 的正确流程：溶解 → 过滤 → 加碱沉淀 → 过滤 → 洗涤 → 灼烧。每一步都有对应的正确装置和操作。

① 溶解合金（甲图辨析）

Al 与稀硫酸反应：$2Al + 3H_2SO_4 = Al_2(SO_4)_3 + 3H_2 \uparrow$；Cu 不反应。
甲用蒸发皿加热——蒸发皿只能用于蒸发溶液，不能用来溶解固体。正确装置：烧杯 + 玻璃棒 + 酒精灯（垫石棉网）。

② 过滤除 Cu（乙图辨析）

溶解后混合物是 $Al_2(SO_4)_3$ 溶液 + Cu 残渣。过滤装置要求：一贴二低三靠——滤纸贴漏斗内壁、滤纸边缘低于漏斗边缘、液面低于滤纸边缘；烧杯嘴靠玻璃棒、玻璃棒靠三层滤纸处、漏斗下端靠烧杯内壁。乙图全部符合，操作规范。

③ 加碱制 Al(OH)₃（丙图辨析）

$Al^{3+} + 3OH^- = Al(OH)_3 \downarrow$。但 Al(OH)₃ 两性：$Al(OH)_3 + NaOH = NaAlO_2 + 2H_2O$，过量 NaOH 会把沉淀溶解。应滴加至恰好完全沉淀，或改用氨水（弱碱，不会溶解 Al(OH)₃）。

④ 灼烧得 Al₂O₃（丁图辨析）

反应：$2Al(OH)_3 \xlongequal{\Delta} Al_2O_3 + 3H_2O$。灼烧固体需用坩埚（耐高温陶瓷材质，可直接加热），蒸发皿是玻璃制品，高温灼烧会炸裂。此外坩埚钳取放、放在泥三角上加热也是规范操作。

🔑 记忆口诀：溶解用烧杯，过滤靠引流；加碱防过量，灼烧换坩埚。

📝知识总结

核心实验仪器辨析

烧杯：溶解、反应容器，可加热（需垫石棉网）
蒸发皿：蒸发结晶溶液用，不能加热固体、不能做反应容器
坩埚：高温灼烧固体用，配套坩埚钳、泥三角、三脚架
漏斗：过滤用，配套玻璃棒引流、烧杯承接

Al(OH)₃ 两性

既能与酸反应：$Al(OH)_3 + 3HCl = AlCl_3 + 3H_2O$
又能与强碱反应：$Al(OH)_3 + NaOH = NaAlO_2 + 2H_2O$
制备时不能用过量强碱，应用氨水或控制 NaOH 用量。
