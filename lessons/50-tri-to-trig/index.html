例2：把 2a−c 装进一根正弦曲线

$a\sin\dfrac{A+C}{2}=b\sin A$ → 求 $B$；锐角三角形 $b=\sqrt3$，求 $2a-c$ 的取值范围

1 题目（2025·哈尔滨模拟）

$\triangle ABC$ 的内角 $A,B,C$ 的对边分别为 $a,b,c$，已知 $a\sin\dfrac{A+C}{2}=b\sin A$。
(1) 求 $B$；　(2) 若 $\triangle ABC$ 为锐角三角形，$b=\sqrt3$，求 $2a-c$ 的取值范围。
📄 原题图片（默认去手写版，可切换）
🔑 全题钥匙：$(A+C)/2=\dfrac{\pi}{2}-\dfrac B2$，正弦一变就是 $\cos\dfrac B2$； 再用一次内角和，整个条件只剩 $B$ 一个未知数。锐角三角形四个字是第(2)问端点的裁判长——两端全开！

2 动画分步演示：拨动角 A，看 2a−c 沿正弦曲线走

点 ▶ 播放 看完整推理；或拖 角 A 滑块，观察 $2a-c=2\sqrt3\sin\!\left(A-\frac{\pi}{6}\right)$ 的动点。

第 1/6 步
实时判定 ✓ 2a−c = 2.45 ∈ (0,3)

🟦 曲线 $y=2\sqrt3\sin\left(A-\frac{\pi}{6}\right)$ · 🟨 锐角三角形允许带 $\left(\frac{\pi}{6},\frac{\pi}{2}\right)$ · 两端全开 → (0,3)

3 完整推导

📌 (1) 半角化 contras：解出 B = π/3

$\dfrac{A+C}{2}=\dfrac{\pi-B}{2}=\dfrac{\pi}{2}-\dfrac B2$，故条件化为 $a\cos\dfrac B2=b\sin A$。

正弦定理（$a=2R\sin A,\;b=2R\sin B$）：$\sin A\cos\dfrac B2=\sin B\sin A$，约去 $\sin A\neq0$：

$\cos\dfrac B2=2\sin\dfrac B2\cos\dfrac B2\;\Rightarrow\;\sin\dfrac B2=\dfrac12\;(\cos\dfrac B2\neq0)\;\Rightarrow\;B=\dfrac{\pi}{3}$
🧠 (2)-① 边角互换：a、c 全用 A 表示

$\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=\dfrac{\sqrt3}{\sqrt3/2}=2$，所以 $a=2\sin A,\;c=2\sin C$，其中 $C=\dfrac{2\pi}{3}-A$。

$2a-c=4\sin A-2\sin\left(\dfrac{2\pi}{3}-A\right)=4\sin A-\sqrt3\cos A-\sin A=3\sin A-\sqrt3\cos A$
🎯 (2)-② 辅助角公式 + 锐角约束
$2a-c=2\sqrt3\sin\left(A-\dfrac{\pi}{6}\right)$

锐角三角形 → 三角全锐：$A\in\left(\dfrac{\pi}{6},\dfrac{\pi}{2}\right)$ 且 $C=\dfrac{2\pi}{3}-A\in\left(\dfrac{\pi}{6},\dfrac{\pi}{2}\right)\Rightarrow A\in\left(\dfrac{\pi}{6},\dfrac{\pi}{2}\right)$。

于是 $A-\dfrac{\pi}{6}\in\left(0,\dfrac{\pi}{3}\right)$，正弦值 $\in\left(0,\dfrac{\sqrt3}{2}\right)$——两端都取不到。

$2a-c\in\boxed{(0,\;3)}$

⚠️ 端点陷阱：$A\to\dfrac{\pi}{6}^+$ 时 $C\to\dfrac{\pi}{2}$ 变直角（不锐）；$A\to\dfrac{\pi}{2}^-$ 时 $A\to\dfrac{\pi}{2}$ 自己变直角。所以 0 和 3 都取不到。

4 跟踪训练 2（2026·杭州模拟）

已知 $\triangle ABC$ 内角 $A,B,C$ 对边 $a,b,c$，$D$ 是 $\triangle ABC$ 外一点。若 $a=b$，且 $\sqrt3(a\cos C+c\cos A)=2b\sin B$。(1) 求角 $B$；(2) 若 $DA=2,\;DC=1$，求四边形 $ABCD$ 面积的最大值。

📄 原题图片
🔑 提示：投影公式 $a\cos C+c\cos A=b$ 又来了！$\sqrt3 b=2b\sin B\Rightarrow\sin B=\dfrac{\sqrt3}{2}$。 $B=\dfrac{\pi}{3}$ 或 $\dfrac{2\pi}{3}$ —— 两个都要检验！
四边形 ABCD 面积的最大值 =

支持 2+5√3/4、(8+5√3)/4、4.165 等写法。

🎉正确！最大值 2 + 5√3/4（B=π/3 分支，∠ADC=150° 时取得）。
🤔

(1) $\sin B=\dfrac{\sqrt3}{2}$，$a=b\Rightarrow A=C$，$B=\dfrac{\pi}{3}$ 或 $\dfrac{2\pi}{3}$ 都要保留。

(2) $S_{ABCD}=S_{\triangle ABC}+S_{\triangle ACD}$，设 $\angle ADC=\theta$：$AC^2=b^2=2^2+1^2-2\cdot2\cdot1\cos\theta=5-4\cos\theta$，$S_{\triangle ACD}=\sin\theta$。

若 $B=\dfrac{\pi}{3}$（等边）：$S_{ABC}=\dfrac{\sqrt3}{4}b^2$，$S=\sin\theta+\dfrac{\sqrt3}{4}(5-4\cos\theta)=\dfrac{5\sqrt3}{4}+\sin\theta-\sqrt3\cos\theta\le\dfrac{5\sqrt3}{4}+2$（$\tan\theta=-\dfrac{1}{\sqrt3}$，$\theta=150°$）。

若 $B=\dfrac{2\pi}{3}$：$S_{ABC}=\dfrac{\sqrt3}{12}b^2$，$S\le\dfrac{5\sqrt3}{12}+\dfrac{2\sqrt3}{3}=\dfrac{13\sqrt3}{12}\approx1.88$，较小。

综合：$S_{\max}=\boxed{2+\dfrac{5\sqrt3}{4}}\approx 4.17$（$B=\dfrac{\pi}{3}$，$\angle ADC=150°$ 时取得）
🏁 最终答案
(1) $B=\dfrac{\pi}{3}$　(2) $2a-c\in(0,\;3)$
跟训2：B=π/3 或 2π/3，S_max = 2+5√3/4　·　口诀：锐角裁判管端点，两端全开记心间
