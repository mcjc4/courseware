📖 公式解构

标准形式：$y = A\sin(\omega x + \varphi) + b$，四个参数各有明确的几何意义：

A —— 振幅（Amplitude）
控制波浪的高度。$|A|$ 越大，波浪起伏越剧烈。$A < 0$ 时图像关于 x 轴对称翻转。
ω —— 角频率（Angular frequency）
控制波浪的疏密。$\omega$ 越大，波浪越密（周期 $T = \frac{2\pi}{\omega}$ 越小）。$\omega > 0$ 是标准情况。
φ —— 初相（Initial phase）
控制左右平移。$\varphi > 0$ 时向左平移 $\left|\frac{\varphi}{\omega}\right|$ 个单位，$\varphi < 0$ 时向右平移。
b —— 平衡位置（Vertical shift）
控制上下平移。图像关于直线 $y = b$ 上下对称（不再关于 x 轴对称）。

考点①已知参数 → 画图

例：已知 $y = 2\sin\left(2x + \frac{\pi}{3}\right) + 1$，求各量
  • 振幅：$|A| = |2| = \boldsymbol{2}$
  • 周期：$T = \frac{2\pi}{\omega} = \frac{2\pi}{2} = \boldsymbol{\pi}$
  • 初相：$\varphi = \boldsymbol{\frac{\pi}{3}}$
  • 相位平移：$-\frac{\varphi}{\omega} = -\frac{\pi/3}{2} = \boldsymbol{-\frac{\pi}{6}}$（即向左平移 $\frac{\pi}{6}$）
  • 平衡位置：$y = b = \boldsymbol{1}$
  • 最大值：$b + |A| = 1 + 2 = \boldsymbol{3}$
  • 最小值：$b - |A| = 1 - 2 = \boldsymbol{-1}$
易错：单调性区间求法（整体代换）：
令 $u = 2x + \frac{\pi}{3}$，则 $y = 2\sin u + 1$。
$\sin u$ 单调递增区间是 $\left[-\frac{\pi}{2} + 2k\pi,\ \frac{\pi}{2} + 2k\pi\right]$，代入 $u$ 解出 $x$：
$-\frac{\pi}{2} + 2k\pi \leq 2x + \frac{\pi}{3} \leq \frac{\pi}{2} + 2k\pi \Rightarrow x \in \left[-\frac{5\pi}{12} + k\pi,\ \frac{\pi}{12} + k\pi\right]$

考点②由图像 → 求参数

已知图像特征反推 A, ω, φ, b 是高考高频题型。

图像描述（完整自洽）：波峰最大值 $y = 3$，波谷最小值 $y = -1$，周期 $T = \pi$，平衡线 $y = 1$，且波峰位于 $x = \frac{\pi}{12}$。
第一步：求 b —— 平衡线即 $y = b$，故 $\boldsymbol{b = 1}$。
第二步：求 A —— 由波峰、波谷与平衡线的距离关系：
$|A| = \frac{\text{最大值} - \text{最小值}}{2} = \frac{3 - (-1)}{2} = 2$
波峰在平衡线上方（开口向上），故 $\boldsymbol{A = 2}$。
第三步：求 ω —— $T = \pi$，由 $T = \frac{2\pi}{\omega}$ 得：
$\omega = \frac{2\pi}{T} = \frac{2\pi}{\pi} = \boldsymbol{2}$。
第四步：求 φ —— 波峰处（正弦取最大值 1）：$\omega x + \varphi = \frac{\pi}{2} + 2k\pi$。
代入已知 $x = \frac{\pi}{12}$、$\omega = 2$：
$2 \cdot \frac{\pi}{12} + \varphi = \frac{\pi}{2} \Rightarrow \frac{\pi}{6} + \varphi = \frac{\pi}{2} \Rightarrow \boldsymbol{\varphi = \frac{\pi}{3}}$。
验证：把四个参数代入原式 $y = 2\sin(2x + \frac{\pi}{3}) + 1$：
$x = \frac{\pi}{12}$ 时，$y = 2\sin(\frac{\pi}{6} + \frac{\pi}{3}) + 1 = 2\sin(\frac{\pi}{2}) + 1 = 2 + 1 = 3$ ✅（波峰）
$x = 0$ 时，$y = 2\sin(\frac{\pi}{3}) + 1 = \sqrt{3} + 1 \approx 2.732$ ✅（无需额外过点条件，参数已自洽）
解题口诀：先 b（上下移）→ 再 A（振幅）→ 再 ω（周期）→ 最后 φ（初相）。
⚠️ 前提：图像描述必须自洽——所有给出的特征点（波峰位置、过点、零点）代入后能同时成立。如果推出矛盾，说明读题有误或题设本身出错。

考点③图像变换（两种路径）

$y = \sin x \ \longrightarrow\ y = 2\sin\left(2x + \frac{\pi}{3}\right) + 1$

方法一：先平移 → 后伸缩（推荐，不易错）

  1. $y = \sin x$
  2. 向左平移 $\frac{\pi}{3}$ 个单位：$y = \sin\left(x + \frac{\pi}{3}\right)$
  3. 横坐标压缩为原来的 $\frac{1}{2}$：$y = \sin\left(2x + \frac{\pi}{3}\right)$
  4. 纵坐标伸长为原来的 2 倍：$y = 2\sin\left(2x + \frac{\pi}{3}\right)$
  5. 向上平移 1 个单位：$y = 2\sin\left(2x + \frac{\pi}{3}\right) + 1$ ✓

方法二：先伸缩 → 后平移（易错！）

  1. $y = \sin x$
  2. 横坐标压缩为原来的 $\frac{1}{2}$：$y = \sin(2x)$
  3. 向左平移 $\boldsymbol{\frac{\pi}{6}}$ 个单位（不是 $\frac{\pi}{3}$！）：$y = \sin\left(2\left(x + \frac{\pi}{6}\right)\right) = \sin\left(2x + \frac{\pi}{3}\right)$
  4. 纵坐标伸长为原来的 2 倍：$y = 2\sin\left(2x + \frac{\pi}{3}\right)$
  5. 向上平移 1：$y = 2\sin\left(2x + \frac{\pi}{3}\right) + 1$ ✓
易错点：先伸缩后平移时，平移量是 $\frac{|\varphi|}{\omega}$，而不是 $|\varphi|$。很多同学直接平移 $\frac{\pi}{3}$，导致错误。
建议：答题时优先使用"先平移后伸缩"，更简单、出错率低。

考点④求单调区间（整体代换法）

以 $y = 2\sin(2x + \frac{\pi}{3}) + 1$ 为例，求其单调递增区间。

三步法：
① 换元：令 $u = 2x + \frac{\pi}{3}$，则原函数变为 $y = 2\sin u + 1$。
② 解三角：$\sin u$ 的单调递增区间为 $\left[-\frac{\pi}{2} + 2k\pi,\ \frac{\pi}{2} + 2k\pi\right]\ (k \in \mathbb{Z})$。
③ 代回解 x： $$-\frac{\pi}{2} + 2k\pi \leq 2x + \frac{\pi}{3} \leq \frac{\pi}{2} + 2k\pi$$ $$-\frac{\pi}{2} - \frac{\pi}{3} + 2k\pi \leq 2x \leq \frac{\pi}{2} - \frac{\pi}{3} + 2k\pi$$ $$-\frac{5\pi}{6} + 2k\pi \leq 2x \leq \frac{\pi}{6} + 2k\pi$$ $$\boldsymbol{-\frac{5\pi}{12} + k\pi \leq x \leq \frac{\pi}{12} + k\pi \quad (k \in \mathbb{Z})}$$
口诀：外层三角 + 内层一次 → 整体代换 → 解不等式。$\omega < 0$ 时先利用诱导公式把负号提到外面。
