🧪 铝土矿变 Al₂O₃ · 实验装置判断题

高考常考 实验操作 装置正误 元素化合物

四个图、四个操作、只有一个站得住脚。先预热，再上场 PK。

🔧 预热：Al₂O₃ 制备四步曲

从铝合金（Al + Cu）到 Al₂O₃，我们按「溶-滤-沉-烧」四步走：

1

溶解

稀硫酸溶解 Al
$\ce{2Al + 3H2SO4 -> Al2(SO4)3 + 3H2 ^}$
2

过滤

除去不溶 Cu
滤纸上：Cu
滤液：Al₂(SO₄)₃
3

沉淀

加碱得 Al(OH)₃
$\ce{Al^3+ + 3OH- -> Al(OH)3 v}$
4

灼烧

得 Al₂O₃
$\ce{2Al(OH)3 ->[\triangle] Al2O3 + 3H2O}$
Step 1 · 溶解：稀硫酸能溶铝不能溶铜，所以铜留在滤渣里。**注意**：Al 与稀硫酸常温就能反应，不需要酒精灯加热。
📝 原题

9. 实验室用铝合金(含 Al、Cu)制备 Al₂O₃，下列相关原理、装置及操作正确的是（ ）

A
用图甲装置溶解铝合金
❌ 错：①烧杯下没垫石棉网，直接加热错误；②Al 与稀硫酸常温反应，不需要酒精灯。
B
用图乙装置过滤溶解后混合物
✅ 对：漏斗嘴贴烧杯壁、玻璃棒引流、滤纸紧贴漏斗壁——标准「一贴二低三靠」。
C
用图丙制备 Al(OH)₃
❌ 错：加过量 NaOH 会把生成的 Al(OH)₃ 溶解：$\ce{Al(OH)3 + OH- -> AlO2- + 2H2O}$。应改用弱碱氨水 $\ce{NH3·H2O}$。
D
用图丁装置灼烧 Al(OH)₃ 制 Al₂O₃
❌ 错：灼烧固体应在坩埚中进行，蒸发皿用于加热溶液。且加热固体时试管口应略向下倾斜（或坩埚盖斜盖）。

A 错 图甲的溶解装置有两个硬伤

① 烧杯不能直接加热，烧杯底面积大受热不均，必须垫石棉网；

② Al 与稀硫酸常温即可反应：$\ce{2Al + 3H2SO4 -> Al2(SO4)3 + 3H2 ^}$，而且 Al 表面有氧化膜，加热反而容易让 Cu 被氧化。

口诀记一下：烧杯烧瓶平底瓶，加热都要石棉垫；试管口小底又稳，直接加热不用衬。

B 对 过滤操作完美踩中「一贴二低三靠」

✅ 一贴：滤纸紧贴漏斗内壁（不留气泡）
✅ 二低：滤纸边缘低于漏斗边缘，液面低于滤纸边缘
✅ 三靠：烧杯嘴靠玻璃棒、玻璃棒靠三层滤纸处、漏斗嘴下端靠烧杯内壁

图中玻璃棒引流方向、漏斗嘴贴杯壁都画对了，是教科书级示范。

C 错 「过量 NaOH」会让 Al(OH)₃ 自己溶了

生成的 Al(OH)₃ 是两性氢氧化物，遇到强碱会变成可溶性的偏铝酸钠：

$$\ce{Al(OH)3 + NaOH -> NaAlO2 + 2H2O}$$

想沉淀 Al³⁺ 又不让它溶解，应该用弱碱氨水 $\ce{NH3·H2O}$，氨水是弱电解质，即使过量也不会让 Al(OH)₃ 溶解：

$$\ce{Al^3+ + 3NH3·H2O -> Al(OH)3 v + 3NH4+}$$

D 错 灼烧固体要用坩埚，不是蒸发皿

蒸发皿是给溶液蒸发结晶用的（比如把 NaCl 水溶液蒸干）。要高温灼烧固体（Al(OH)₃ 分解需要 400°C 以上），必须用坩埚 + 坩埚钳，配泥三角、三脚架。

$$\ce{2Al(OH)3 ->[高温] Al2O3 + 3H2O}$$

仪器功能对照表：
坩埚 → 灼烧固体 / 蒸发皿 → 蒸溶液 / 烧杯 → 常温配液 / 试管 → 少量反应
🎯 最后 30 秒 · 解题口诀
烧杯加热垫石棉，
过滤认准三靠边，
Al(OH)₃ 遇碱别过量，
灼烧固体用坩埚！
本题答案：B（过滤装置操作规范，其他三个各有一个经典操作错误）
